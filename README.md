# Throne of Combat 1

A 3D MOBA-style arena fighter built in Godot 4.

## Features
- 4 Unique Characters with 5 skills each.
- Brutality Finisher system.
- Wave-based AI combat.
- Chapter Select and Save/Load system.

## Setup
1. Open Godot 4.
2. Import the project using `throne_of_combat_1/project.godot`.
3. Follow instructions in `throne_of_combat_1/docs/PIPELINE.md` to generate and import assets.
